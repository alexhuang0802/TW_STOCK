## SITE ARCHITECTURE OVERVIEW

Carrefour Taiwan operates TWO separate web properties:

1. www.carrefour.com.tw - Corporate/marketing WordPress site (WP 6.8.3)
   - Theme: "carrefourtw" custom theme
   - Contains: news, announcements, winner lists, store events (spmevent posts)
   - REST API: /wp-json/wp/v2/ (standard WP endpoints)
   - Catalogues page uses a Vue.js plugin "vulcan-block-catalogue-list"
     that loads dynamically from category_ids [34,35,37,38,39,137]
   - These category IDs are NOT exposed in the WP REST API (custom taxonomy)
   - The catalogue data is loaded client-side by JavaScript (requires JS rendering)

2. online.carrefour.com.tw - E-commerce/online shopping platform
   - Separate domain, likely Next.js or similar SPA
   - Cross-domain GA tracking configured: online.carrefour.com.tw/tw
   - Could NOT be accessed via WebFetch (permission denied)
   - Needs direct HTTP probing to determine tech stack and API endpoints

3. c4fast.carrefour.com.tw - Fast delivery service ("家速配")
   - Could NOT be accessed via WebFetch (permission denied)
   - Likely a separate SPA application

## DATA SOURCE 1: WordPress REST API (www.carrefour.com.tw)
======================================================================

### Endpoint: /wp-json/wp/v2/posts
- All posts are in category 7 ("uncategorized-zh")
- No custom post types for catalogues/promotions exposed via REST API
- Post types available: post, page, attachment, nav_menu_item, wp_block,
  wp_template, wp_template_part, wp_global_styles, wp_navigation,
  wp_font_family, wp_font_face (NO custom types)
- Taxonomies: category, post_tag, nav_menu, wp_pattern_category (NO custom)

### Useful WP API Queries for Product Deals:

1. Search for "特價" (special price):
   GET /wp-json/wp/v2/posts?per_page=100&search=特價
   Returns: Store-specific product promotions with actual prices
   Examples found:
   - 香鹽雞翅咖啡 特價$149
   - 5D雕花石墨烯火山紗可嗅被 特價2680元
   - SKECHERS 2件特價再8折 3件特價再7折
   - KFC 5塊雞+2顆原味蛋撻... 特價$368（原價$565）
   - Mos Burger 13號厚比薩+烤雞腿4支+點心 特價$429
   - TAKASHIMA 按摩椅 NT$9,300起; AI小沙發 NT$29,999

2. Search for "優惠" (discount/deal):
   GET /wp-json/wp/v2/posts?per_page=100&search=優惠
   Returns: Store events with discount info
   Examples:
   - NIKE 全場最低55折起
   - 台灣除臭襪 5雙$1088、14雙$2000
   - 咖啡豆 任3包立即享8折優惠
   - 定食8 消費額滿升級花蛤湯
   - 連假有購讚 (holiday deals)
   - 家電指定品牌活動

3. All recent posts (last 100):
   GET /wp-json/wp/v2/posts?per_page=100
   Returns: Mix of winner lists, system notices, and promotions

### Post Content Structure:
- Posts use WordPress rendered HTML content
- Many posts are IMAGE-ONLY (content is just an <img> tag)
- Product details are embedded in post titles (e.g., "☞NIKE☞家樂福重新店 最低55折起")
- Price information can be in titles or HTML content
- Posts with slug pattern "spmevent*" are store-specific promotions
- Posts with slug pattern "winnerlist-*" are winner announcements (not useful)
- Posts with slug pattern "vip*" are VIP member deals

## DATA SOURCE 2: Catalogues Vue.js Plugin
======================================================================

The /catalogues/ page has this Vue component:
  <div id="carrefour-tw-vulcan-block-catalogue-list"
       vu-attributes='{"category_ids":[34,35,37,38,39,137]}'>

Category mapping (from page navigation):
  34 or similar = 量販促銷 (Hypermarket Promotions)
  35 or similar = 主題企劃 (Theme Projects)
  37 or similar = 促銷快報 (Promotion Express)
  38 or similar = 超市促銷 (Supermarket Promotions)
  39 or similar = 新店開幕 (New Store Openings)
  137 or similar = Unknown

The actual catalogue items are:
- Loaded dynamically via JavaScript (Vue.js)
- NOT available through the WP REST API
- Likely fetched via admin-ajax.php or a custom REST endpoint not in the public API index
- Requires JavaScript rendering (Playwright) to capture
- Each catalogue is typically a PDF or image-based flyer, NOT structured product data
