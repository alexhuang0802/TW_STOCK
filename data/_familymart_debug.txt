FamilyMart HAS extensive combo deal product data, but it is stored as
STATIC HTML with plain text (no JSON APIs, no __NEXT_DATA__, no structured
product data attributes). Parsing requires text-based extraction from
known URLs.

The main combo deal page is:
  https://nevent.family.com.tw/freshfood/

This single page contains ALL combo meal tiers (49/59/69/79/99/109元)
with hundreds of individual products. This is the PRIMARY target for scraping.

### Parsing Strategy
Products are organized as plain text under category headers within price
tier sections. A scraper needs to:
1. Fetch the page HTML
2. Parse text content by identifying tier sections (49/59/69/79)
3. Within each tier, identify category headers (壽司手卷/飯糰, 熱食, etc.)
4. Split product names by Chinese comma (、) delimiter
5. Associate each product with its tier price

## TECHNICAL NOTES FOR SCRAPER IMPLEMENTATION

### Data Source
Primary URL: https://nevent.family.com.tw/freshfood/
- Static HTML page, no API
- Products are plain text separated by Chinese commas (、)
- No product-level CSS classes or data attributes
- Images are tier-level only (./img/49.jpg etc.), not per-product
- Page changes with each promotion period (dates in page content)

### Recommended Scraping Approach
1. Fetch https://nevent.family.com.tw/freshfood/ with requests + BeautifulSoup
2. Extract all text content
3. Identify price tier sections by looking for patterns like "49" "59" "69" "79"
4. Within each tier, identify category headers
5. Split product names by "、" (Chinese enumeration comma)
6. Create structured combo deal objects:
   {
     "deal_name": "餐餐超值配 49元",
     "combo_price": 49,
     "food_items": ["油蔥雞汁飯糰", "煙燻培根飯糰", ...],
     "food_category": "壽司手卷/飯糰",
     "included_drinks": ["光泉無加糖優酪乳", ...],
     "upgrade_15_drinks": ["熱經典拿鐵", ...],
     "upgrade_25_drinks": ["大熱經典拿鐵", ...],
     "start_date": "2026-03-04",
