6. DATA AVAILABLE WITHOUT IMAGE PROCESSING
==================================================
From HTML, we CAN extract per-campaign:
  - title (campaign name)
  - image_url (the 690x400 banner)
  - date_range (activity period, e.g., "2026/03/05-2026/04/01")
  - link (detail page URL)
  - disclaimer text

From HTML, we CANNOT extract:
  - Individual product names (e.g., 可口可樂)
  - Product prices (e.g., 單件25元)
  - Deal types per product (e.g., 買1送1)
  - Product images

==================================================
7. CONCLUSION
==================================================
OK超商 promotion detail pages are IMAGE-BASED, similar to 美廉社.
All product-level information (product names, prices, deal types like
買1送1, 單件25元) is embedded within banner images (690x400 JPG files).

The HTML only contains:
  - Campaign-level metadata (title, dates, link)
  - A single large image per promotion

To extract product-level data, options would be:
  a) OCR on the banner images (similar approach needed as 美廉社)
  b) Manual data entry
  c) Check if shop.okmart.com.tw has structured product data (separate site)

RECOMMENDATION: The current scraper already extracts everything available
from the HTML. To get product-level data, OCR/vision processing on the
690x400 banner images would be required. The scraper should be enhanced to:
  1. Extract the date range (currently missing - "2026/03/05-2026/04/01")
  2. Download/reference the detail page image URLs (/userfiles/xxx.jpg)
     which contain the actual product details
  3. Potentially use OCR/vision API to extract product info from images
